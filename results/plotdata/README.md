# Plot data (time series of the figures)

One CSV per scenario and case, `<S>_<case>.csv`, `S` in S1, S2, S3, `case` in `compensated`,
`non_compensated`, `px4_tuned`, `px4_shipped`. Generated by `scripts/export_plotdata.py` from the
same processing as the figures (`scripts/postprocess.py`).

Runs (the ones plotted): S1 -> `logs/S1_<case>.ulg` (single real-time flight); S2, S3 -> repetition 1,
`logs/<S>/<S>_<case>_r1.ulg` (4x real time). `px4_shipped` is not drawn in the S1-S3 state figures
(only in `sitl_S3_xy.pdf`) but is exported as well.

Sampling: controller rate (1 kHz, `ijc_debug`), window t = 0-20 s (S1) or 0-60 s (S2, S3).
Frames: NED (x north, y east, z down) for positions, velocities and forces; body FRD for torques.
Positions are relative to the hover point `p_d(0)`, as in the figures.

| Column | Meaning |
|---|---|
| `t_s` | scenario time [s] (t = 0 when the scenario starts) |
| `p_d_*_m` | desired position [m] |
| `p_ekf_*_m` | position estimated by EKF2 (used by the controller) [m] |
| `p_gt_*_m` | Gazebo ground-truth position [m] (~60 Hz, linearly interpolated; origin aligned with the EKF at t = 0) |
| `v_d_*_mps`, `v_ekf_*_mps`, `v_gt_*_mps` | desired, EKF and ground-truth velocity [m/s] |
| `theta_d_deg`, `phi_d_deg`, `psi_d_deg` | desired attitude (pitch, roll, yaw; ZYX Euler) [deg]; PX4 cases: PX4's attitude setpoint |
| `theta_deg`, `phi_deg`, `psi_deg` | attitude (EKF) [deg] |
| `F_actual_*_N` | S1: injected force `m F`; S2/S3: aerodynamic force measured in Gazebo (IjcAeroSystem, 50 ms centered moving average) [N] |
| `F_hat_*_N` | `m F_hat` of the translational observer [N] (PX4 cases: observers only logged, not used by the controller) |
| `T_actual_*_Nm` | S1: injected torque `J T`; S2/S3: measured aerodynamic moment about the CoM (50 ms average) [N m] |
| `T_hat_*_Nm` | `J T_hat` of the rotational observer [N m] |
| `f_N` | collective thrust command [N] (PX4 cases: thrust setpoint converted with IJC_FMAX) |
| `tau_*_Nm` | torque command [N m] (PX4 cases: torque setpoint converted with IJC_TMAX_*) |

Parameters of the runs: `results/params.txt`; metrics: `results/metrics.csv`, `results/metrics_runs.csv`.
